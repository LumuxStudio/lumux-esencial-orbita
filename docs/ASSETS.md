# Recursos y referencias

Fotografías producidas para esta demostración con ImageGen y optimizadas a WebP local. Son escenas y productos ficticios, no fotografías de clientes reales. Variantes de 768 px para móvil y hasta 1600 px para escritorio. No se copiaron imágenes de las referencias.

Direcciones de generación: arquitectura de piedra caliza en paisaje desértico y luz de tarde; interior de madera y piedra con patio; mesa de cocina al fuego sobre fondo oscuro y manos de cocinero; perfume ficticio FORMA de vidrio verde sobre pedestal lavanda. Cada proyecto contiene solo sus recursos correspondientes. Las ilustraciones SVG de respaldo y piezas gráficas se construyeron en código.

Referencias consultadas para fotografía protagonista, escala tipográfica, contraste y presencia de escultura digital:

- [Extrafazant](https://www.extrafazant.nl/)
- [h2a](https://www.h2a.lu/)
- [Imersion](https://www.imersion.io/)
- [Cerebrium](https://cerebrium.ai/)
- [Illoca](https://illoca.unseen.co/)

Estas referencias orientaron la dirección visual; no son plantillas importadas ni clientes de las marcas ficticias.
